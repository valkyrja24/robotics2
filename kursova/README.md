# Курсова робота

Тема одна на всіх, варіант у кожного свій → `kartka/README.md`.
Повні переліки місій, середовищ і ускладнень —
[`matrytsia-variantiv.md`](matrytsia-variantiv.md).
Графік і критерії кожного етапу — у теках `praktyka/` і `zakhyst/`.

> **Розробка та дослідження системи автономного керування мобільним
> роботом для виконання заданої місії**

## ⭐ Головне, що варто зрозуміти на першому тижні

**Курсова не пишеться в грудні. Вона збирається з того, що ви
робите на парах, починаючи з тижня 2.**

| Тиждень | Що з'являється | У який розділ записки піде |
|---|---|---|
| 2 | картка варіанта, критерій успіху | Вступ + Додаток А |
| 4 | сцена, покази датчиків | Опис середовища |
| 5 | параметри регулятора, заміри | Обґрунтування рішень |
| 6 | діаграма станів, відео | Обґрунтування рішень |
| 7 | карта, критерій успіху | Опис середовища + Додаток В |
| 9 | два прогони з різними параметрами | Випробування |
| 12 | таблиця прогонів, «що завадило» | Випробування + Аналіз відмов |
| 15 | зведення й пояснення | увесь текст |

⭐ Дев'ять етапів, кожен — один вечір максимум. Записка на 20 сторінок
пишеться не за три ночі, а по шматку щотижня.

## Структура записки

| Розділ | Стор. |
|---|---|
| Вступ: місія, середовище, ускладнення, критерій успіху | 1–2 |
| Аналіз аналогів: як цю **місію** розв'язують | 3–4 |
| Опис середовища й робота: карта, розміри, датчики, скріншоти | 3–4 |
| ⭐ Обґрунтування рішень: чому цей алгоритм і ці параметри | 4–5 |
| ⭐ Випробування: **не менше 10 прогонів**, таблиця, статистика | 3–4 |
| ⭐ Аналіз відмов: що саме зламалось і чому | 2–3 |
| Висновки | 1–2 |
| Джерела, додатки | — |

**18–25 сторінок** основного тексту без додатків.

### ⛔ Розділу «Теоретичні основи» немає

Переказ підручника не приймається й не оцінюється.

Замість нього — **«Обґрунтування проєктних рішень»**, де кожне
твердження спирається **або на джерело, або на ваш прогін**.

> Абзац без посилання на джерело чи на власний вимір —
> порожній абзац.

### ⭐ «Аналіз відмов» — найдорожчий розділ

Тут ви описуєте, що **не** спрацювало: робот застряг у куті на
прогоні 4; на прогоні 7 датчик дав хибний нуль; при `Kp = 0.8`
пішов у розгойдування.

Такий текст неможливо ні згенерувати, ні позичити — його немає
в чужих прогонах. І він же найкорисніший: саме тут видно,
що ви розумієте систему.

⚠️ Заповнюйте стовпець «що завадило» в `journal.md` **одразу після
прогону**. Через місяць ви не згадаєте.

## Оформлення

Повні вимоги — методичка [`metodychka-kursova-rob-2026.pdf`](metodychka-kursova-rob-2026.pdf)
(ДСТУ 3008:2015, джерела — ДСТУ 8302:2015). ⭐ **Пишіть записку одразу
в шаблоні** [`zapyska-shablon.docx`](zapyska-shablon.docx): поля, шрифти, нумерація
й підписи там уже налаштовані — скопіюйте його як `kursova/zapyska.docx`.

| Параметр | Значення |
|---|---|
| Обсяг | 18–25 сторінок основного тексту (від вступу до висновків) |
| Шрифт, інтервал | Times New Roman 14, інтервал 1,5, абзац 1,25 см, за шириною |
| Поля | ліве 30 мм, праве 15 мм, верхнє й нижнє 20 мм |
| Нумерація сторінок | праворуч угорі; на титулі, завданні й рефераті номер не ставиться |
| Склад | титул → завдання → реферат → зміст → вступ → 3 розділи → висновки → джерела → додатки |
| Рисунки | «Рисунок 2.1 — Назва» **під** рисунком, посилання в тексті **обов'язкове** |
| Таблиці | «Таблиця 3.1 — Назва» **над** таблицею, посилання в тексті обов'язкове |
| ⚠️ Лістинги | **у тексті не більше 15 рядків**, решта — у додаток Б |
| Джерела | ≥ 12, з них ≥ 5 англомовних; за ДСТУ 8302:2015, URL з датою звернення; бажано не старші за 2018 (крім класики й стандартів) |
| Додатки | А — картка варіанта, Б — код, В — сцена, Г — таблиця прогонів і відео, Д — декларація ШІ |

П'ять пунктів. Усе інше — понад це.

2. Робот проходить **вашу** трасу — хоч якось

4. Записка за мінімальною структурою
5. Захист

⭐ Це фізично робиться **до тижня 9**. Далі семестр іде на те,
щоб зробити краще, а не на те, щоб устигнути.

## Використання систем ШІ

| Частина | Правило |
|---|---|
| Аналіз аналогів, редагування тексту | ✅ можна, з декларацією; оригінал без ШІ — у додаток |
| Код керування | ✅ можна, з декларацією; згенероване коментується |
| ⛔ Карта, прогони, числа, аналіз відмов, відео | **тільки ваші** |
| ⛔ Захист | без сторонньої допомоги |

Декларацію заповнюєте в **записці, додаток Д** (форма — у шаблоні). Записи в кінці `journal.md` — чернетка для неї.

⭐ **Зазначення факту використання ШІ не знижує оцінку.** Знижує
нездатність пояснити те, що ви подали.
